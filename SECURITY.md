# Security Policy

OpenFloodAI is early-stage software and is not yet ready for operational flood warning use.

## Reporting Vulnerabilities

Please do not open public issues for suspected security vulnerabilities. Instead, contact the maintainers through the repository security advisory process when available, or use the private reporting channel listed by the project maintainers.

Include:

- A description of the issue.
- Steps to reproduce, if applicable.
- Potential impact.
- Suggested mitigation, if known.

## Sensitive Data

Do not commit:

- Camera credentials or stream URLs.
- API keys, tokens, passwords, or private certificates.
- Raw imagery containing sensitive location or personal information.
- Private datasets or trained model artifacts.

## Operational Safety

OpenFloodAI is designed to support human decision-making. It should not be used as the sole basis for emergency warnings, evacuations, or public safety decisions.
